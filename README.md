# CRM-система для управления клиентами

CRM-система для управления клиентами, рекламными кампаниями, услугами, потенциальными клиентами, контрактами и
активными клиентами. Разработана на Django с использованием PostgreSQL.

## 🛠 Технологический стек

- **Python 3.10+**
- **Django 5.2.16**
- **PostgreSQL** (как СУБД)
- **Pytest** + **pytest-django** + **pytest-cov** - для тестирования
- **Pylint** + **pylint-django** - для статического анализа кода
- **mypy** - для проверки типов
- **pre-commit** - для автоматической проверки кода перед коммитом
- **python-dotenv** - для управления переменными окружения
- **Bootstrap 5** - для интерфейса

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/ваш-username/crm-system.git
cd crm-system
```

### 2. Создание и активация виртуального окружения

```bash
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
.venv\Scripts\activate      # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта со следующим содержанием:

```env
SECRET_KEY=ваш_секретный_ключ
DB_NAME=crm_db
DB_USER=postgres
DB_PASSWORD=ваш_пароль
DB_HOST=localhost
DB_PORT=5432
DEBUG=True
```

### 5. Создание базы данных PostgreSQL

```bash
createdb -U postgres crm_db
```

### 6. Применение миграций

```bash
python manage.py migrate
```

### 7. Создание суперпользователя

```bash
python manage.py createsuperuser
```

### 8. Запуск сервера

```bash
python manage.py runserver
```

Откройте браузер и перейдите по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)

## 🔐 Права доступа и группы

В системе предусмотрены роли:

| Роль | Описание |
|---|---|
| Администратор | Полный доступ, управление пользователями через админку |
| Оператор | Работа с лидами (создание, редактирование, удаление) |
| Маркетолог | Работа с услугами и рекламными кампаниями |
| Менеджер | Работа с контрактами и активными клиентами |

### Создание групп и прав

Группы создаются автоматически при применении миграций через сигнал `post_migrate`.

Для создания групп можно также выполнить команду:

```bash
python manage.py setup_groups
```

## 🔍 Статический анализ и линтеры

### Проверка через Pylint

```bash
pylint apps/
```

### Проверка через mypy

```bash
mypy apps/
```

### Автоматическая проверка через pre-commit

Для установки pre-commit:

```bash
pre-commit install
```

После этого проверки будут запускаться автоматически при каждом коммите.

## 📊 Статистика

На странице `/ads/statistic/` отображается статистика по рекламным кампаниям:

- Количество лидов
- Количество активных клиентов
- Соотношение дохода от контрактов к затратам на рекламу

На главной странице (`/`) отображается общая статистика:

- Количество услуг
- Количество рекламных кампаний
- Количество лидов
- Количество активных клиентов

### Обработка ошибок

При `DEBUG=False` ошибки обрабатываются стандартными страницами 404 и 500.

Для `on_delete=models.PROTECT` предусмотрена защита от удаления связанных объектов.
